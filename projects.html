Agentic Math Reasoning Assistant

Python, LangChain, Chroma, SymPy, OpenAI API | 2026

  • Built an AI agent that decides whether to retrieve math concepts or run a calculation, instead of following one fixed pipeline.
  • Gave the agent two tools: a Chroma-based search over math articles and a SymPy-based calculator for solving and verifying expressions.
  • Tested it on 50 questions to check whether it chose the right tool. After rewriting its instructions, correct tool use rose from 34% to 62%.

Hybrid Retrieval RAG over FDA Drug Labels

Python, LangChain, FAISS, BM25, HuggingFace, OpenAI API | 2026

  • Built a RAG pipeline over FDA prescription drug labels that combines dense and keyword-based retrieval.
  • Used token-aware chunking with a custom tiktoken length function for precise chunk sizes.
  • Combined FAISS dense retrieval with BM25 keyword search in an ensemble retriever. On an auto-generated evaluation set, the hit rate rose from 90% to 96%.

RAG System over Research Papers

Python, Sentence-Transformers, FAISS, NLTK, tiktoken, OpenAI API | 2026

  • Built a RAG pipeline from scratch, without LangChain, over arXiv papers: ingestion, chunking, retrieval and generation.
  • Wrote sentence-aware chunking with token-based overlap, and dense retrieval using Sentence-Transformer embeddings in FAISS.
  • Designed an evaluation harness that generates synthetic test questions from the source documents with an LLM, so no manual labeling is needed.

Solving Differential Equations using Deep Learning

Python, TensorFlow, Overleaf (LaTeX) | 2024

  • Designed physics-informed neural networks (PINNs) to solve singularly perturbed differential equations, reaching 95% accuracy against known analytical solutions.
  • Compared Adagrad, Momentum, Adadelta, Nesterov Accelerated Gradient and RMSprop to find the most stable training setup.
  • The findings formed the basis of the publication below.
