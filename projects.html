Agentic Math Reasoning Assistant

2026

An AI agent that decides whether to retrieve math concepts or run a calculation, instead of following one fixed pipeline. It has a Chroma search tool over math articles and a SymPy calculator for verifying expressions.

  • Tested on 50 questions to check whether it chose the right tool.
  • Rewriting its instructions raised correct tool use from 34% to 62%.
  • Python
  • LangChain
  • Chroma
  • SymPy
  • OpenAI API

Hybrid Retrieval RAG over FDA Drug Labels

2026

A RAG pipeline over FDA prescription drug labels that combines dense and keyword-based retrieval.

  • Token-aware chunking with a custom tiktoken length function.
  • FAISS dense search plus BM25 in an ensemble retriever.
  • Hit rate rose from 90% to 96% on an auto-generated evaluation set.
  • LangChain
  • FAISS
  • BM25
  • HuggingFace
  • OpenAI API

RAG System over Research Papers

2026

A RAG pipeline built from scratch, without LangChain, over arXiv papers.

  • Sentence-aware chunking with token-based overlap.
  • Dense retrieval with Sentence-Transformer embeddings in FAISS.
  • An evaluation harness that generates synthetic test questions with an LLM, so no manual labeling is needed.
  • Sentence-Transformers
  • FAISS
  • NLTK
  • tiktoken
